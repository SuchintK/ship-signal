Follow the Rust and JSON names

The report command calls Workflow::report. It reads the saved row into StoredReport and builds a Report for callers. The ProductReport inside it contains the demand denominator, review flag, and grouped needs.

Serde uses product when reading or writing either struct as JSON. Rust callers use productReport. The lint allowance is scoped to the camel-case field.
