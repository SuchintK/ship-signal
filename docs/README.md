# Ship Signal documentation

Ship Signal turns recurring customer feature requests into evidence-backed tickets and implements approved work through draft pull requests.

## Index

| Document | Purpose |
| --- | --- |
| [Glossary](../GLOSSARY.md) | Plain-language definitions of product and technical terms used across the repository and design discussions. |
| [01 — Grill session](01-grill-session/README.md) | Settled product scope, feedback rules, approval process, execution schedule, architecture choices, and remaining implementation decisions. |
| [02 — Technical decisions](02-technical-decisions/README.md) | Ten review findings, current decisions, unresolved questions, alternatives, recommendations, and ADR assessments for follow-up sessions. |
| [03 — Architecture decision records](03-adr/README.md) | Rationale, alternatives, and consequences for consequential architecture decisions. |

The grill-session record captures the current agreed design. It is a product and design record, not a claim that the implementation exists. Items explicitly listed as unresolved remain open.
